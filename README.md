# شمارشگر فارسی دو نمایشگره

برنامه دسکتاپ برای نمایش عدد و فراخوانی آن از پنجره کنترل، همراه پنجره جداگانه نمایش روی مانیتور دوم.

## استفاده

۱. در تنظیمات ویندوز نمایشگرها را در حالت Extend قرار دهید.
۲. برنامه را باز و «باز کردن نمایشگر» را انتخاب کنید. در صورت وجود نمایشگر دوم، پنجره روی آن تمام‌صفحه باز می‌شود؛ در غیر این صورت روی نمایشگر اصلی باز می‌شود.
۳. عدد را وارد و ثبت کنید یا با دکمه افزایش، یک واحد اضافه کنید. عدد بین ۰ تا ۹۹۹٬۹۹۹٬۹۹۹ است.
۴. تعداد تکرار و فاصله را ثبت و دکمه خواندن را انتخاب کنید. توقف خواندن نیز امکان‌پذیر است. وضعیت در دستگاه ذخیره می‌شود.

## صدا

منبع معرفی‌شده Q-Taraz در زمان ساخت در دسترس نبود و هیچ فایل صوتی از آن در این پروژه وجود ندارد. برنامه به صدای فارسی موتور گفتار سیستم وابسته است؛ اگر صدای فارسی در Electron شناسایی نشود پیام خطا نمایش می‌دهد. دسترسی و کیفیت صدای فارسی به نسخه و تنظیمات ویندوز بستگی دارد و باید روی دستگاه مقصد آزموده شود.

## توسعه و ساخت

Node.js 22 لازم است:

```sh
npm ci
npm test
npm start
npm run dist:win
```

خروجی نصاب ۶۴ بیتی NSIS در پوشه `dist` قرار می‌گیرد. ساخت خودکار ویندوز در GitHub Actions فایل نصب را به صورت artifact منتشر می‌کند. نصاب امضای دیجیتال ندارد و ممکن است Windows SmartScreen هشدار دهد.
