# شمارشگر فارسی دو نمایشگره

برنامه دسکتاپ برای نمایش عدد و فراخوانی آن از پنجره کنترل، همراه پنجره جداگانه نمایش روی مانیتور دوم.

## استفاده

۱. در تنظیمات ویندوز نمایشگرها را در حالت Extend قرار دهید.
۲. برنامه را باز و «باز کردن نمایشگر» را انتخاب کنید. در صورت وجود نمایشگر دوم، پنجره روی آن تمام‌صفحه باز می‌شود؛ در غیر این صورت روی نمایشگر اصلی باز می‌شود.
۳. عدد را وارد و ثبت کنید یا با دکمه افزایش، یک واحد اضافه کنید. پس از افزایش، عدد جدید با تنظیمات تکرار خوانده می‌شود. عدد بین ۰ تا ۹۹۹٬۹۹۹٬۹۹۹ است.
۴. تعداد تکرار و فاصله را ثبت و دکمه خواندن را انتخاب کنید. توقف خواندن نیز امکان‌پذیر است.
۵. رنگ و فونت عدد را از بخش «عدد و ظاهر» انتخاب کنید؛ تغییرات در نمایشگر دوم اعمال و همراه وضعیت در دستگاه ذخیره می‌شوند. فونت‌های وزیرمتن و آی‌بی‌ام پلکس عربی همراه برنامه هستند.

## صدا

فایل‌های صوتی از آرشیو Q-Taraz ارسالی استخراج شده‌اند و برای خواندن به صدای سیستم نیاز نیست. مجموعه موجود فقط اعداد ۱ تا ۹۹۹ را پوشش می‌دهد؛ برای صفر و اعداد بزرگ‌تر پیام خطا نمایش داده می‌شود و عدد ناقص خوانده نمی‌شود. نمایش و شمارش همچنان تا ۹۹۹٬۹۹۹٬۹۹۹ پشتیبانی می‌شوند. پخش روی ویندوز مقصد باید آزموده شود. مجوز انتشار عمومی فایل‌های صوتی در آرشیو مشخص نشده است.

## حذف برنامه

برنامه را ببندید و در ویندوز به Settings → Apps → Installed apps بروید؛ Persian Counter را پیدا کنید و Uninstall را انتخاب کنید. هنگام حذف، در صورت نمایش گزینه حذف داده‌های برنامه، آن را فقط زمانی انتخاب کنید که می‌خواهید وضعیت و تنظیمات نیز پاک شوند. حذف برنامه بدون انتخاب آن، داده‌ها را برای نصب مجدد نگه می‌دارد.

## توسعه و ساخت

Node.js 22 لازم است:

```sh
npm ci
npm test
npm start
npm run dist:win
```

خروجی نصاب ۶۴ بیتی NSIS در پوشه `dist` قرار می‌گیرد. ساخت خودکار ویندوز در GitHub Actions فایل نصب را به صورت artifact منتشر می‌کند. نصاب امضای دیجیتال ندارد و ممکن است Windows SmartScreen هشدار دهد.
